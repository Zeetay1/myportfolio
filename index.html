2. Selected Work

The following figures summarise publicly available projects. Each represents a complete, deployed system accessible via the provided URL.

Figure 1: Pseudogen Live
Converts natural language problem statements into structured pseudocode across multiple output styles. Demonstrates applied NLP and code generation at the intersection of language models and developer tooling.
Stack: Python, JavaScript URL: pseudogen-frontend.fly.dev
Figure 2: Real-time Anomaly Detector Live
Detects anomalies in a live time-series stream using a model that adapts in real time without manual retraining. The system handles concept drift through online learning, maintaining detection accuracy as data distributions shift.
Stack: Python, Streaming URL: real-time-anomaly.fly.dev
Figure 3: Self-Improving Ad Copy Agent Live
An autonomous agent that generates advertising copy for direct-to-consumer brands, evaluates its own output against defined quality criteria, promotes winning variants as few-shot examples for subsequent inference, and improves measurably over time without gradient-based retraining. Implements a closed-loop agentic feedback architecture.
Stack: FastAPI, Agentic AI URL: self-improving-agent-delta.vercel.app
Figure 4: Counterfactual Explanation Engine for Black-Box Models In Development
An explainable AI system for generating counterfactual explanations of black-box model predictions. Addresses the interpretability gap in production ML systems by surfacing minimal feature perturbations that would alter model output.
Stack: Explainability, ML Status: Beta
